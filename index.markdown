# 雑談

## 2026-11-03

昨日は休暇取って、今日は祝日。土曜～火曜の四連休。

昨日と今日は、StrataとQwen3.8-Flash-Nextでコーディング試したが、
これはなかなかいい感じかも。
ローカルLLM特有のアホっぽさが、今のところ全然感じられない。
まったく普通に使える。
ただ、コンテキストサイズが、ちょっとしたコード修正で一気に100kトークン行ったことがあったので、
コンテキストサイズがボトルネックになるかも。
それでも128k使えるだけで、今までとは比べ物にならんけど。
速度は、今のところは全く問題ないというか、一般的なローカルLLMと変わらない感じ。
SSDがSATAなのが不安材料だったけど、そこもあまり気にならない。
しかしこうなってくると、メモリもっとたくさん積んでSSDも速いやつにして、
グラボも2枚載せたくなってくる。
PCパーツ高騰が痛すぎる。
今後もしローカルLLMがもっと普及したら、更に高価になる可能性もありそう。

この連休は、KIBORGを毎日遊んでた気がする。
今日は初めて、たぶんラスボスまで辿り着いた。
ラスボスは、今のところはパリィが必要ないので、むしろ1ボス、2ボスより楽かも。
しかし、なんかこのゲームは、自分の体力が妙に長持ちする回があって、
それがインプラントとかスキルの効果なのか、たまたま敵の攻撃が当たってないだけなのか、
そこがよく分からん時がある。
あと、武器持ってるとコンボが変わるんで、
武器を持ってた方が強いのか素手の方が強いのかもよく分からん。
あと、後半になると回避する敵とか盾持ってる敵とかいるんだが、
こういうヤツの倒し方もよく分からん。
